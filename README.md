# DocuForensic AI — Fake Document & Tampering Detector

A full-stack, cyber-forensic document verification application configured to run seamlessly across **all browsers, mobile devices, local networks, public web, and standalone file mode**.

---

## 🌐 5 Flexible Ways to Host & Run

### 1. Direct Localhost Browser (Fresh Port)
Open in Chrome, Edge, Firefox, Brave, Safari, or Opera:
👉 **[http://localhost:3000](http://localhost:3000)**

### 2. Wi-Fi & Mobile Network (Any Phone / Tablet / Computer)
The server binds to `0.0.0.0`. Any mobile device on your Wi-Fi can open it directly:
👉 **`http://10.253.158.80:8000`** *(or your local network IP)*
- Inside the app, click **"Host & Connect"** to show a scannable **QR code** for your mobile camera!

### 3. Public Web Tunnel (Accessible Anywhere Worldwide)
Share with anyone on the internet without router port forwarding:
👉 **[https://clear-dancers-wonder.loca.lt](https://clear-dancers-wonder.loca.lt)**

### 4. 1-Click Desktop Launcher
- Double-click the **`Fake Document Detector`** shortcut on your Desktop.
- Or double-click `run.bat` in the project folder to start the server and open your default browser automatically.

### 5. Serverless Static Hosting & 1-Click Cloud Deploy
Because all core forensic algorithms run 100% in client-side JavaScript:
- **Zero-Server Mode:** Double-click `public/index.html` directly in any browser.
- **1-Click Free Cloud Deploy:** Drop the project folder into [Vercel](https://vercel.com) or [Netlify](https://netlify.com) using the pre-configured `vercel.json` and `netlify.toml` files.

---

## 📱 Installing as a Native App
- **Desktop (Windows / Mac / Linux):** Open the site in Chrome or Edge and click **"Install App"** on the header bar.
- **Mobile (Android / iOS):** Open on mobile and tap **"Install App"** (Chrome) or **Share > Add to Home Screen** (Safari).
- **Offline Support:** The Service Worker pre-caches all inspection algorithms for 100% offline functionality.

## 🔍 Forensic Vectors Supported
1. **Error Level Analysis (ELA):** Multi-spectral quantization error differential matrices.
2. **Interactive Comparison Slider:** Side-by-side split screen comparing Original vs. Forensic Heatmap.
3. **High-Frequency Noise & Laplacian Variance:** Detects digital cut-and-paste and smoothed regions.
4. **Copy-Move / Clone Detector:** Identifies duplicated stamps, seals, and repeated digits.
5. **ICAO 9303 MRZ Passports Checksum Engine:** Modulo-10 weight `[7, 3, 1]` verification for passports and national ID cards.
6. **Financial Arithmetic Cross-Check:** Automatic calculation verification on invoice balances.
7. **Camera Scanner Viewfinder:** Capture and inspect physical documents directly from your device camera.
8. **Forensic Audit Reports:** Export printable certificates and JSON diagnostic data.
